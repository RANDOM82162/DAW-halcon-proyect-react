# Halcon React - Frontend

Este es el cliente frontend para el proyecto Halcón, desarrollado utilizando React y Vite.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone <url-del-repositorio>
   cd halcon-react
   ```
2. Instala las dependencias de Node:
   ```bash
   npm install
   ```

## Variables de Entorno

Crea un archivo `.env` en la raíz del proyecto y configura las siguientes variables:

- `VITE_API_URL`: URL base de la API del backend (ej. `https://web-production-8c8e3.up.railway.app/api`).

## Comandos

- Iniciar el servidor de desarrollo:
  ```bash
  npm run dev
  ```
- Compilar el proyecto para producción:
  ```bash
  npm run build
  ```
- Previsualizar la compilación de producción localmente:
  ```bash
  npm run preview
  ```
